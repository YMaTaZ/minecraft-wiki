# Minecraft 1.21: Tricky Trials Update

Minecraft Java Edition **1.21** was released on **June 13, 2024**, known as the *Tricky Trials Update*.  
This update added new challenge-focused dungeons, weapons, and mobs.

## Key Features
- 🕳 Trial Chambers
- 🗡 Mace weapon
- 🌬 Breeze and Bogged mobs
- 🔮 New dungeon loot and rewards
