# Minecraft 1.20: Trails & Tales

Minecraft Java Edition **1.20** was released on **June 7, 2023**, the *Trails & Tales Update*.  
This update focused on player expression, archaeology, and storytelling elements.

## Key Features
- 🏺 Archaeology system
- 🐫 Camel and Sniffer mobs
- 🌸 Cherry wood set
- 📜 Hanging signs and armor trims
