# Minecraft 1.13: Update Aquatic

Minecraft Java Edition **1.13** was released on **July 18, 2018**, known as the *Update Aquatic*.  
This update revamped water physics and added many ocean-related features.

## Key Features
- 🌊 New ocean biomes and structures
- 🐬 Dolphins, Tropical Fish, Drowned mobs
- 🪸 Coral, Sea Pickles, Kelp
- 🔄 Command changes and improvements
