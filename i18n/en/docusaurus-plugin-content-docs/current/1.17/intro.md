# Minecraft 1.17: Caves & Cliffs (Part I)

Minecraft Java Edition **1.17** was released on **June 8, 2021**, the first part of the Caves & Cliffs update.  
It introduced many new underground and world-building elements.

## Key Features
- 🪩 Copper and oxidation mechanics
- 🐐 Goats and Glow Squid
- 🟦 New stone and cave blocks
- 🔭 Spyglass and new utility items
