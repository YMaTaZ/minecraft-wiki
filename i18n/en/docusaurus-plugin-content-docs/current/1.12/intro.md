# Minecraft 1.12: World of Color Update

Minecraft Java Edition **1.12** was released on **June 7, 2017**, known as the *World of Color Update*.  
This update added many colorful blocks, a new advancement system, and improvements to crafting.

## Key Features
- 🟥 Concrete and Concrete Powder with 16 colors
- 🟪 Glazed Terracotta decorative blocks
- 🦜 Parrots and new mobs
- 🏆 Advancements replacing achievements
- 📜 Improved Recipe Book
