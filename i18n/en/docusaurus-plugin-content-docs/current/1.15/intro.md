# Minecraft 1.15: Buzzy Bees

Minecraft Java Edition **1.15** was released on **December 10, 2019**, known as the *Buzzy Bees Update*.  
It focused on adding bee-related content and many technical improvements.

## Key Features
- 🐝 Bees and beehives
- 🍯 Honey blocks and bottles
- 🐝 New bee behavior and mechanics
- ⚙️ Performance improvements and bug fixes
