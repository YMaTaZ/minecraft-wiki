# Minecraft 1.16: Nether Update

Minecraft Java Edition **1.16** was released on **June 23, 2020**, known as the *Nether Update*.  
It completely expanded the Nether dimension with new biomes, blocks, mobs, and gear.

## Key Features
- 🪨 New Nether biomes and terrain
- 🐗 Piglins and Hoglins
- ⚒️ Netherite gear and upgrades
- 🔥 New blocks and lighting
