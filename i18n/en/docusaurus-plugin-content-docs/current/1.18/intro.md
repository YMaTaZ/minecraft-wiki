# Minecraft 1.18: Caves & Cliffs (Part II)

Minecraft Java Edition **1.18** was released on **November 30, 2021**, completing the Caves & Cliffs update.  
It revamped world generation with new heights, depths, and terrain features.

## Key Features
- 🏔 Expanded world height (-64 to 320)
- 🕳 Large cave systems
- ⛰ New mountain generation
- 🌿 New surface terrain
