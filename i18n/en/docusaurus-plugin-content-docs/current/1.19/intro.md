# Minecraft 1.19: The Wild Update

Minecraft Java Edition **1.19** was released on **June 7, 2022**, known as the *Wild Update*.  
It expanded biomes, mobs, and exploration, especially in deep dark and mangrove swamps.

## Key Features
- 🌳 Mangrove swamps
- 🦣 Warden and Deep Dark
- 🐸 Frogs, Tadpoles
- 🧱 Mud and new building blocks
