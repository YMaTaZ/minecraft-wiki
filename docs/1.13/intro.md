# Minecraft 1.13：水域更新（Update Aquatic）

Minecraft Java Edition 1.13 于 **2018 年 7 月 18 日**发布，是著名的 **水域更新（Update Aquatic）**，带来了海洋生态系统的重大升级。

---

## ✨ 主要新增内容

- 🌊 **沉船与海底遗迹**
- 🐠 **新生物**：热带鱼、海豚、溺尸
- 🧜 **三叉戟武器** 和附魔
- 🪸 珊瑚、海带、水草等装饰性方块
- 🧱 命令系统全面重构（命令统一化）
