# Minecraft 1.21 新机制与系统

## 🕳 试炼密室（Trial Chambers）

- 一种新地下结构，拥有随机房间、陷阱和刷怪笼。
- 为挑战玩家而设计，可触发多波敌对冲突。
- 内含珍稀战利品和独特机制。

## 🗡 重锤武器（Mace）

- 新武器类型，拥有专属攻击动画。
- 可配合重锤附魔释放特殊效果。 :contentReference[oaicite:5]{index=5}

## 🔮 新附魔机理

- 重锤专属附魔（如致密、破甲、风爆）增强战斗能力。 :contentReference[oaicite:6]{index=6}

## 🛠 方块与机制互动

- 试炼刷怪笼、宝库等方块可与敌对行为和奖励机制联动。 :contentReference[oaicite:7]{index=7}
