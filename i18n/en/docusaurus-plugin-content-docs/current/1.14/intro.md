# Minecraft 1.14: Village & Pillage Update

Minecraft Java Edition **1.14** was released on **April 23, 2019**, called the *Village & Pillage Update*.  
Villages and villagers were fully redesigned and new mechanics were introduced.

## Key Features
- 🏘️ New village layouts and professions
- 🏹 Pillagers and raid mechanics
- 🐈 New cat mob
- 🛠️ Many new blocks and decorative elements
