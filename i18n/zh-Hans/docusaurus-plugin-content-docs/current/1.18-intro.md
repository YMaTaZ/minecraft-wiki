# Minecraft 1.18：洞穴与山崖更新（第二部分）

Minecraft Java Edition **1.18** 于 **2021 年 11 月 30 日** 发布，重点是 **世界生成系统的重构**，包括新的高度限制、真实地形生成以及大型洞穴系统。

---

## ✨ 主要新增内容

- 🏔 世界高度从 Y 0~256 扩展至 -64~320
- 🕳 巨型洞穴系统（噪声洞穴、条带洞穴等）
- ⛰ 新增山地群系类型
- 🧊 深板岩完全替代基岩层
- 🎵 新音乐与音效
